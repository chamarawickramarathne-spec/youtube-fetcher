1. Title
YouTube Fetcher

2. Short Description
A fast, clean YouTube video downloader for Windows. Paste a link, pick a quality, and save videos as MP4 or audio as MP3 - works out of the box with no extra software to install. Available for both 32-bit and 64-bit Windows.

3. Long Description
YouTube Fetcher is a lightweight desktop app for Windows that makes downloading YouTube videos and audio effortless. Just paste a video link and the app instantly fetches the available qualities. Choose from Best Quality (merged video+audio), 720p, 1080p, or Audio Only (MP3), and the download starts automatically - with live progress, speed, and ETA shown right on the screen.

Built with a clean, dark interface, YouTube Fetcher supports multiple parallel downloads, a persistent download history, a custom save folder, and smart auto-paste from your clipboard. Behind the scenes it uses yt-dlp, so it stays reliable even as YouTube changes. The app also includes a built-in auto-update system - the version is shown right next to the app name and a one-click update button keeps you on the latest release at all times.

Version 2.1.1 focuses on making the app friendlier for first-time users. YouTube now requires a small JavaScript engine to download, so YouTube Fetcher bundles its own tiny runtime - there is no longer any need to install Node.js, Python, or anything else. Downloading to a custom folder on any drive now works exactly as chosen, without silently falling back to the default folder. And the browser-cookie prompt has been redesigned: public videos download with no prompt at all, and sign-in is requested only for age-restricted or private videos, with a clear choice to allow once, always, or not now.

Version 2.1.0 added major security hardening and dual-architecture support. Both 32-bit (x86) and 64-bit (x64) Windows installers are provided, and the update system automatically selects the correct installer for your system. Every update download is verified with a SHA-256 checksum, TLS certificate verification is enforced, YouTube URLs are validated before download, and file handling is hardened against path-traversal and data-corruption attacks. The entire installer is only ~90 MB (down from 450 MB in older versions).
